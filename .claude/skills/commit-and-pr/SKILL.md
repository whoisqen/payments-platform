# commit-and-pr

- Commit rules are in `CLAUDE.md` (Conventions); one commit, one reason; refactoring before behaviour changes.
- PR description: Why, Changes (one entry per commit title), How verified, Risk and rollback, PCI impact, Checklist; at most 400 changed lines excluding generated files.
