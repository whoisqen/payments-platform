# postmortem

- Blameless template; timeline from logs and metrics; impact against the SLO error budget; root cause; what went well and badly.
- Each follow-up becomes a GitHub issue labelled `postmortem-action`; missing tests become a separate task.
- Store the draft in `docs/postmortems/`.
