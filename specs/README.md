# specs

Every change to the platform starts with one specification. Specifications are the working input for agents, which is why they live here and not in `docs/`.

```
specs/
├── README.md        # index: number, title, status, milestone (generated by /spec)
├── _templates/      # spec.md, plan.md, tasks.md, handoff.md; humans only
└── NNN-<slug>/      # NNN is the next number and is never reused
    ├── spec.md      # what and why
    ├── plan.md      # how
    ├── tasks.md     # T1..Tn: items for agents
    └── handoffs/    # requests between agents: <from>-<to>.md
```

Lifecycle of `status`: `draft` -> `approved` (human gate of the plan phase) -> `in-progress` -> `implemented` or `superseded`. The build phase does not start for a specification that is not `approved`; an `implemented` specification is never edited, a new change is a new specification.

Check with `tools/lint/spec-lint`.
